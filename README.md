# One-Line Roast: The Gadget You Use Every Day

Entry for the [make.fun competition "One-Line Roast: The Gadget You Use Every Day"](https://make.fun/c/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610).

`main.ts` writes one original roast line — at most 200 characters — to `/output/entry.txt`. The program is fully deterministic: the same line on every run, no clock, no network, no input.

The roast:

> My phone unlocks for my sleeping face, my cat, and a photo of me, but never for me, awake, holding it.

Run it with Node 22+:

```sh
node main.ts
cat /output/entry.txt
```
